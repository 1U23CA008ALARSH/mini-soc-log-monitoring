# Day 1 – SOC Fundamentals

## Objective

Learn the basic concepts of a Security Operations Center (SOC) and understand the role of a SOC Analyst L1.

## What I Learned

### What is a SOC?

SOC stands for Security Operations Center.

A SOC is a team or facility responsible for monitoring, detecting, analyzing, and responding to security threats.

### What does a SOC Analyst L1 do?

A SOC Analyst L1 is the first line of defense.

Main responsibilities include:

- Monitor SIEM, EDR, firewall, and other security tools.
- Analyze security alerts.
- Identify true threats and false positives.
- Document findings.
- Escalate complex or critical incidents.

## Event

An event is an activity that happens in a system or network.

Example:

A user logs in to a computer.

## Log

A log is a record of an activity or event.

Example:

Windows records a successful or failed login in the Security log.

## Alert

An alert is a notification generated by a security tool or SIEM when activity may be suspicious.

Important:

An alert does not automatically mean a confirmed attack.

## Incident

An incident is a confirmed or sufficiently substantiated security issue that requires a response.

## Alert vs Incident

Example:

20 failed login attempts → Alert

Account confirmed compromised → Incident

## Day 1 Workflow

Event → Log → Alert → Investigation → Incident → Response
